# content

The text of the document.

- Goes here: One chapter or section per file, numbered in reading order, plus the main file.
- Does not go here: Figures (figures/), references (bibliography/), templates (templates/).
- Naming: NN-short-title, for example 03-methods.tex.

## Contents

- `00-guia.md`: the guide for students, in Spanish. Start here.
- `01-defensa.yml`: the text of every slide, the speaker script and the seconds per slide. `scripts/build_deck.py` reads it.
- `02-ensayos.md`: the rehearsal plan.
