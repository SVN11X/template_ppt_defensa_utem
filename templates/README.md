# templates

Institution or publisher templates.

- Goes here: Class files, styles and title page templates, unmodified when possible.
- Does not go here: Your own content.
- Naming: Keep the original file names.

## Contents

- `utem-defense-template.potx`: the PowerPoint template for the defense.
- `logos/`: the UTEM horizontal logo, as SVG and PNG.
- `brand-manual/`: the UTEM visual identity manual and its logo guides, with their original file names.

The logos and the manual belong to Universidad Tecnológica Metropolitana. They are not covered by this repository's license. Use them as the manual allows.
